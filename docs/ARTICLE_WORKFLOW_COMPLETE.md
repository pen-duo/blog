## 🚀 快速开始

### 方式一：智能创建（推荐新手）
```bash
pnpm new
```
按照提示逐步创建文章，系统会自动配置所有必要信息。

### 方式二：快速创建（推荐熟练用户）
```bash
pnpm new:quick "文章标题" 分类
```

**示例：**
```bash
pnpm new:quick "React Hooks 最佳实践" develop
pnpm new:quick "个人项目复盘" project
pnpm new:quick "2024年终总结" reference
```

## 📝 文章撰写流程

### 第一步：确定文章主题和分类

#### 📂 分类说明
| 分类 | 说明 | 适用内容 | 推荐标签 |
|------|------|----------|----------|
| `develop` | 开发技术 | 技术教程、框架使用、工具介绍 | JavaScript, React, Vue, TypeScript |
| `program` | 编程实践 | 架构设计、最佳实践、代码规范 | 架构, API, 数据库, 性能优化 |
| `project` | 项目分享 | 项目复盘、开源项目、产品设计 | 开源项目, GitHub, 产品设计 |
| `lifestyle` | 生活感悟 | 职场心得、学习方法、个人成长 | 思考, 成长, 职场, 经验分享 |
| `reference` | 年度总结 | 年终总结、阶段回顾、未来规划 | 年终总结, 回顾, 规划, 目标 |

### 第二步：创建文章文件

#### 🎯 智能创建流程
1. **运行创建命令**
   ```bash
   pnpm new
   ```

2. **选择文章分类**
   - 系统会显示所有可用分类
   - 根据文章内容选择最合适的分类

3. **输入文章信息**
   - 文章标题（必填）
   - URL slug（可自动生成）
   - 文章描述（用于SEO和预览）
   - 选择标签（系统会推荐相关标签）

4. **系统自动配置**
   - 生成完整的 frontmatter
   - 选择合适的封面图
   - 创建文章模板结构

### 第三步：编写文章内容

#### 📖 文章结构模板
```markdown
---
slug: article-url-slug
title: 文章标题
date: 2024-01-15
authors: default
tags: [标签1, 标签2, 标签3]
keywords: [关键词1, 关键词2]
description: 文章描述
image: 封面图URL
---

文章简介或引言

<!-- truncate -->

## 📝 概述

文章概述内容...

## 🚀 主要内容

### 子标题1

内容...

```javascript
// 代码示例
console.log('Hello, World!');
```

### 子标题2

内容...

## 💡 核心要点

- 要点1
- 要点2
- 要点3

## 🎯 总结

总结内容...

## 📚 参考资料

- [参考链接1](https://example.com)
- [参考链接2](https://example.com)
```

#### ✍️ 写作建议

1. **标题设计**
   - 使用具体、描述性的标题
   - 包含核心关键词
   - 控制在50字以内

2. **内容结构**
   - 使用清晰的标题层级（H2, H3）
   - 添加适当的 emoji 增强可读性
   - 保持段落简洁，避免过长

3. **代码示例**
   - 使用围栏代码块（```）
   - 指定编程语言以启用语法高亮
   - 添加必要的注释

4. **图片使用**
   - 优先使用高质量图片
   - 添加 alt 文本
   - 考虑图片加载性能

## 🎨 文章优化流程

### 第一步：内容预览
```bash
# 启动开发服务器
pnpm start

# 在浏览器中预览
# http://localhost:3000
```

### 第二步：格式美化
```bash
# 美化所有文章格式和封面图
pnpm beautify
```

**美化功能包括：**
- 优化 frontmatter 格式
- 智能选择封面图
- 添加 emoji 到标题
- 优化代码块格式
- 生成文章摘要

### 第三步：元信息完善
```bash
# 确保所有文章都有完整元信息
pnpm add-meta
```

**会自动添加：**
- SEO 友好的 slug
- 智能生成的描述
- 相关关键词
- 合适的标签
- 高质量封面图

### 第四步：封面图优化
```bash
# 修复封面图链接问题
pnpm fix-covers

# 为无封面的文章添加封面图
pnpm add-covers
```

## 🚀 发布部署流程

### 第一步：代码提交

#### 📝 提交前检查清单
- [ ] 文章内容已完成
- [ ] 格式已优化（`pnpm beautify`）
- [ ] 元信息已完善（`pnpm add-meta`）
- [ ] 构建测试通过（`pnpm build`）
- [ ] 本地预览正常（`pnpm serve`）

#### 💾 Git 操作流程
```bash
# 1. 检查文件状态
git status

# 2. 添加所有更改
git add .

# 3. 提交更改（使用规范的提交信息）
git commit -m "feat: 新增文章《文章标题》

- 添加技术教程文章
- 优化封面图和元信息
- 修复格式问题"

# 4. 推送到远程仓库
git push origin main
```

#### 📋 提交信息规范
```
类型: 简短描述

详细描述（可选）
- 具体改动1
- 具体改动2
```

**提交类型：**
- `feat`: 新功能或新文章
- `fix`: 修复问题
- `docs`: 文档更新
- `style`: 格式调整
- `refactor`: 重构代码
- `chore`: 其他更改

### 第二步：自动部署

#### 🔄 Vercel 自动部署
1. **触发部署**

3. **部署完成**

#### 📊 部署状态检查
- 访问 [Vercel Dashboard](https://vercel.com/dashboard)
- 检查部署日志
- 确认部署成功

## 💡 最佳实践

### 📖 内容创作

#### 1. 文章规划
- **主题明确**：每篇文章只讲一个主题
- **受众定位**：明确文章的目标读者
- **价值导向**：确保文章对读者有实际价值

#### 2. 写作技巧
- **开头引人**：用问题、故事或数据开头
- **结构清晰**：使用标题、列表、代码块
- **实例丰富**：提供具体的代码示例
- **总结到位**：用要点总结核心内容

#### 3. SEO 优化
- **关键词密度**：自然地使用相关关键词
- **标题优化**：包含核心关键词
- **描述精准**：150字以内的精准描述
- **内链建设**：适当引用站内其他文章

### 🎨 视觉设计

#### 1. 封面图选择
- **主题相关**：与文章内容高度相关
- **质量优先**：选择高清、专业的图片
- **风格统一**：保持整体视觉风格一致

#### 2. 排版规范
- **标题层级**：合理使用 H1-H6
- **段落间距**：保持适当的空白
- **代码高亮**：指定编程语言
- **emoji 使用**：适度使用增强可读性

### 🔧 技术规范

#### 1. 文件命名
- **有意义的名称**：反映文章主要内容
- **避免特殊字符**：使用英文、数字、连字符
- **保持简洁**：避免过长的文件名

#### 2. 代码规范
- **语法正确**：确保代码可以运行
- **注释清晰**：添加必要的解释
- **格式统一**：使用一致的缩进和命名

#### 3. 链接管理
- **有效性检查**：定期检查外部链接
- **描述性文本**：避免使用"点击这里"
- **新窗口打开**：外部链接在新窗口打开

## 🆘 故障排除

### 🚨 常见问题及解决方案

#### 1. 构建失败
**问题**：`pnpm build` 失败
```bash
# 解决步骤
pnpm fix-mdx              # 修复 MDX 错误
pnpm add-meta             # 完善元信息
pnpm clear && pnpm build  # 清除缓存重新构建
```

#### 2. 封面图 404
**问题**：文章封面图无法显示
```bash
# 解决步骤
pnpm fix-covers           # 修复图片链接
pnpm add-covers           # 添加缺失的封面图
```

#### 3. 路由冲突
**问题**：重复的文章路由
```bash
# 检查 slug 是否重复
grep -r "slug:" blog/
# 手动修改重复的 slug
```

#### 4. 元信息缺失
**问题**：文章缺少必要的元信息
```bash
pnpm add-meta             # 自动添加完整元信息
```
