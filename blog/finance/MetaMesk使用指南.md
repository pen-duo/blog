# MetaMask 使用指南

**从固定扩展、多链切换，到多账户与安全分离**

装好 **MetaMask** 之后，怎么顺手用、怎么切网络、怎么查地址和多账户，以及**怎么把练习钱包和真金白银的钱包分开**，是很多人会卡住的地方。下面按「固定扩展 → 界面导航 → 网络与多链 → 地址与区块浏览器 → 多账户 → 安全分离」顺一遍。

<!-- truncate -->

---

## 一、把扩展固定到工具栏

为了随时能打开**钱包**，建议把 MetaMask **钉在浏览器工具栏**。

1. 点浏览器右上角**拼图图标**（扩展程序）。
2. 在列表里找到 **MetaMask**，点右侧的**图钉**。
3. 狐狸图标会一直留在工具栏上，任意网页都能快速点开。

---

## 二、两种界面：弹出视图 vs 扩展视图

| 方式 | 怎么打开 | 适合做什么 |
|------|----------|------------|
| **弹出视图** | 点工具栏上的 MetaMask 图标 | **快速操作**：签名、看余额、确认交易 |
| **扩展视图** | 在弹出窗口右上角点 **⋯** → 选「扩展视图」 | **复杂操作**：在新标签页全屏用，管理网络、多账户等更顺手 |

按任务选：临时签一笔用弹出，要改设置、加网络用扩展视图。

---

## 三、多链能力与网络切换

### 1. 不只是以太坊：支持所有 EVM 链

很多人以为 MetaMask 只能连以太坊，其实它是**多链钱包**，支持所有基于 **EVM** 的链。**同一套助记词**可以管理多条链上的资产、连各条链上的 **DApp**。

常见 EVM 链举例：**以太坊主网**、**Arbitrum**、**Optimism**、**Base**、**Polygon** 等。MetaMask 也在扩展非 EVM 支持（如 **Solana**）。

### 2. 查看与切换网络

- 钱包**必须连到对应网络**才能看到该链上的资产、才能和该链上的应用交互。
- 点界面**左上角网络下拉框**（默认显示「以太坊主网」）→ 在「选择网络」里选你要的链，或你已添加的自定义网络。

### 3. 添加自定义网络

若列表里没有目标链，可以手动加：

1. 点网络下拉 → 进 **「自定义」** 选项卡。
2. 点 **「添加自定义网络」**。
3. 填网络参数，常用几项：

| 字段 | 说明 |
|------|------|
| **Network name** | 链的名称（如 Polygon Mainnet） |
| **Default RPC URL** | 钱包连这条链用的 **RPC 端点** |
| **Chain ID** | 该链的**唯一数字 ID**，防跨链重放 |

### 4. 启用测试网

**测试网**默认不显示，需要先打开：

1. 点右上角 **⋯** → **「网络」**。
2. 在「管理网络」里拉到最下，打开 **「显示测试网络」**。
3. 启用后会出现 **Sepolia** 等测试网；切到测试网后余额会显示该链资产（如 0 Sepolia ETH）。测试网币可从**水龙头**免费领，用于练手、开发。

## 四、钱包地址与区块浏览器

### 1. 地址是什么、在哪看

- **钱包地址**是你在链上的**公开收款标识**，像「数字邮箱」：别人要给你转**加密货币**或 **NFT**，就需要这个地址。
- 在 MetaMask 里，地址是**一长串以 `0x` 开头的字符**，显示在账户名称下方（如「账户 1」下面）；**点击地址**可复制到剪贴板。

### 2. 用区块浏览器查活动

**区块浏览器**可以查任意地址的余额和交易历史，链上公开可查。

- 常用：**Etherscan**（etherscan.io）、**Blockscout**（eth.blockscout.com，开源方案）。
- 用法：把**钱包地址**粘贴到搜索框，即可看该地址在各链上的余额和交易记录。新钱包会显示余额为 0、无交易。

## 五、多账户的创建与管理

在**同一套 MetaMask 安装**下可以建多个**账户**，方便区分用途（如一个日常、一个开发）。

1. 点左上角**账户名称**下拉（如「账户 1」）。
2. 选 **「添加账户或钱包」** → **「创建新账户」** → **「以太坊账户」**。
3. 给新账户起名（如「账户 2」）→ **「添加账户」**。

注意：**每个账户有各自的钱包地址**，但**所有账户都由同一组 12 个词的助记词（SRP）恢复**。助记词丢了，这个 MetaMask 下的所有账户都找不回来。

## 六、安全要点：开发钱包与主钱包分离

**务必把「练手/开发用的钱包」和「放真钱的钱包」分开**，这是 Web3 里**操作安全（OpSec）** 的基本要求。

| 用途 | 建议 |
|------|------|
| **开发 / 学习钱包** | 只连**测试网**、只做实验和教学；**不要**在里面放真实、大额资产；可能接触未审计合约或恶意站点，风险高。 |
| **真实资金钱包** | 用**全新的浏览器配置文件**（如 Chrome 新建用户），在新配置里**重新安装 MetaMask**，得到**全新的助记词**；这个钱包**只**放个人真金白银，不拿来点不明链接、不连陌生 DApp。 |

这样可以在「实验环境」和「真实资产」之间建一道**防火墙**，大大降低误操作或中招时的损失。

---

## 七、总结

- **固定扩展**：把 MetaMask 钉到工具栏，随时可开。
- **界面**：弹出视图做快速操作，扩展视图做设置与多账户。
- **多链**：支持所有 EVM 链（以太坊、Arbitrum、Optimism、Base、Polygon 等），同一助记词管多链；可**添加自定义网络**（RPC、Chain ID），可**开启测试网**练手。
- **地址**：在账户名下方，点一下复制；用 **Etherscan / Blockscout** 查余额和交易。
- **多账户**：同一安装下可建多个账户、多个地址，但**共用一个助记词**。
- **安全**：**开发钱包**只做测试与学习；**真钱**用**新浏览器配置 + 新装的 MetaMask + 新助记词**，专钱包专用。
